# 自習室予約システム（プロトタイプ）

各校舎の自習室のブース（席）を、生徒がその場でオンライン予約できるようにするシステムです。
面談アプリと同じ構成（Next.js + Supabase + Vercel）で作られています。

## できること

- 管理画面: 校舎ごとに「席数の上限（ブース数）」と「使用できる日時」を設定できる
- 生徒画面: 校舎 → 使用日時 → ブースの順に選び、氏名と生徒番号を入力して予約する
- 一度予約されたブースは、キャンセルされない限り他の生徒は選べない（同時押しにも対応）
- 生徒はログイン不要。予約完了後に表示される専用リンクから自分でキャンセルできる

## 画面

- `/` : トップページ（生徒用・管理者用の入り口）
- `/reserve` : 生徒用の予約画面
- `/admin` : 管理画面（校舎一覧・追加）
- `/admin/[校舎ID]` : 校舎ごとの設定（席数上限・使用日時・予約状況）
- `/cancel/[トークン]` : 予約のキャンセル画面（予約完了時に発行されるリンク）

管理画面には現時点でログイン機能を付けていません（プロトタイプのため）。
本番運用する場合は、面談アプリと同じメールOTPログインを追加することをおすすめします。

## セットアップ手順（非エンジニアの方向け）

ここから下は、実際にこのシステムを動かすための手順です。1行ずつ、何をする操作かを添えて説明します。
不明な点があれば、その時点のエラー画面やメッセージのスクリーンショットを送ってください。

### 手順1: Supabase（データベース）のプロジェクトを作る

1. https://supabase.com にアクセスし、ログイン（アカウントがなければ新規作成）します。
2. 「New project」から新しいプロジェクトを作成します（名前は例えば `study-room-app`）。
3. プロジェクトが作成できたら、左メニューの「SQL Editor」を開きます。
4. このフォルダに入っている `supabase/schema.sql` の中身を全部コピーして、SQL Editorに貼り付け、
   「Run」を押します。これでテーブル（データの入れ物）が作られます。
5. 左メニューの「Project Settings」→「API」を開き、以下の2つの値をメモします。
   - Project URL（例: `https://xxxxxxxx.supabase.co`）
   - `service_role` の Secret key（「Reveal」を押すと表示されます。この値は他人に絶対に見せないでください）

### 手順2: GitHubに新しいリポジトリ（コードの保管場所）を作る

1. https://github.com にログインします。
2. 右上の「+」→「New repository」を選び、リポジトリ名を入力します（例: `study-room-app`）。
   「Public」「Private」はどちらでも構いません。README等は追加せず、空のリポジトリのまま作成してください。
3. 作成できたら、そのリポジトリのURL（例: `https://github.com/あなたのアカウント/study-room-app.git`）を控えておきます。

### 手順3: コードをGitHubに送る（プッシュする）

このフォルダ（`study-room-app`）で、以下のコマンドを1行ずつ実行してください。
それぞれの行が何をするかを添えています。

```
git add .
```
→ 変更したファイルをすべて「次のコミットの対象」に加える行

```
git commit -m "自習室予約システムの初回コミット"
```
→ ここまでの変更を1つの記録（コミット）として保存する行

```
git branch -M main
```
→ ブランチ（作業の流れ）の名前を `main` に統一する行

```
git remote add origin https://github.com/あなたのアカウント/study-room-app.git
```
→ 手順2で作ったGitHubリポジトリを「送り先（origin）」として登録する行
（すでに登録済みという意味の `remote origin already exists` というエラーが出た場合は無視して次に進んでください）

```
git push -u origin main
```
→ ここまでの内容をGitHubに実際に送信する行

### 手順4: Vercelにデプロイする

1. https://vercel.com にログインします（GitHubアカウントでログインできます）。
2. 「Add New...」→「Project」を選び、手順2で作ったGitHubリポジトリ（`study-room-app`）を選択して「Import」します。
3. 「Environment Variables」の欄に、以下の2つを追加します（手順1でメモした値を使います）。
   - `SUPABASE_URL` = Project URL
   - `SUPABASE_SERVICE_ROLE_KEY` = service_role の Secret key
   （どちらも「Secret」のままで問題ありません。`NEXT_PUBLIC_` から始まらない変数なので）
4. 「Deploy」を押します。数分待つと、`https://study-room-app-xxxx.vercel.app` のようなURLが発行されます。

### 手順5: 動作確認

1. 発行されたURLの `/admin` にアクセスし、校舎を1つ追加してみてください（席数上限は1以上にしてください）。
2. 追加した校舎をクリックし、「使用日時」を1つ登録してください。
3. `/reserve` にアクセスし、その校舎・使用日時・ブースを選んで、氏名と生徒番号を入力して予約してみてください。
4. 予約完了画面に出てくる「キャンセルする画面を開く」のリンクから、正しくキャンセルできるかも確認してください。
